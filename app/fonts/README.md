Self-hosted Latin WOFF2 fonts from Google Fonts: Bodoni Moda (regular/italic variable 400–700), Inter (variable 400–700), Allura (400). Original SIL Open Font License files accompany each family. Next.js serves these locally with preloading and adjusted fallback metrics; neither builds nor visitors need a font-service request.

Sources: https://fonts.google.com/specimen/Bodoni+Moda · https://fonts.google.com/specimen/Inter · https://fonts.google.com/specimen/Allura

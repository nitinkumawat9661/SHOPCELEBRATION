# Celebration conversion copy principles

Customer-facing copy should be simple English first, with light Hinglish only where it makes the brand feel human.

## Use
- Clear value before process.
- One obvious next action.
- Specific reassurance near payment and delivery decisions.
- Truthful social proof only when backed by real order data.
- Real scarcity only when stock/capacity/time data makes it true.
- Objective labels such as Best Value only when calculated from catalog value.
- Progress and commitment cues in the hamper builder.
- Friendly recovery for hesitation: budget help, custom request, WhatsApp help.

## Avoid
- Internal implementation details such as OTP architecture, session mechanics, database behavior, or why a technical choice was made.
- Fake percentages, fake popularity, fake low-stock messages, fake countdowns, or manufactured urgency.
- Repeated popups or navigation traps.
- Long Hindi-heavy operational explanations.
- Copy that sounds like policy/legal text inside normal shopping flow unless the user needs the information for the decision.
